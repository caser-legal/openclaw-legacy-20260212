3 USE CASES:

1. QUICK CODING SESSION
   $ cd ~/project
   $ k
   > /add file.swift
   > "Add login feature"
   > /commit
   > Ctrl+C

2. LONG CODING SESSION (Browser)
   $ kimi-web-start
   # Browser opens automatically
   # Close terminal, keep coding
   $ kimi-web-stop  # When done

3. CHECK AI AGENTS
   $ claw
   # Opens TUI to see agent status
   # Or just check reports:
   $ ls ~/.openclaw/workspace/reports/

KEY LOCATIONS:
  Config:     ~/.zshrc (API keys)
  Reports:    ~/.openclaw/workspace/reports/
  Logs:       ~/.openclaw/logs/
  LiteLLM:    ~/Desktop/config.yaml
